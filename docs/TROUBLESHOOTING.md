# 常见问题

## 双击 EXE 没有反应

稍等几秒。单文件 EXE 第一次启动需要释放内部文件。如果仍没有窗口，查看日志：

```text
%LOCALAPPDATA%\AdjustPdf\logs\adjust-pdf.log
```

## 提示 PDF 已加密

当前版本不提供密码输入。请先使用可信 PDF 软件解除密码保护，再处理副本。

## 处理后没有页面发生变化

可能是页面原本 `Rotate = 0`。工具只处理 PDF 旋转属性，不自动判断扫描图像是否拍歪。

## 处理后仍然不能导出文字

扫描 PDF 本质上是图片。固化旋转不会自动增加文本层，需要另外执行 OCR。

## 出现“成功（有警告）”

通常表示页面包含链接、批注或表单区域。请检查输出文件中链接点击位置和表单控件。

## 输出文件在哪里

输出位置留空时，结果在原 PDF 旁边，名称含 `_旋转已固化`。也可以在窗口中选择统一输出目录。

## 为什么没有覆盖原文件

这是安全设计。处理特殊 PDF 时可能遇到兼容问题，保留原文件便于恢复。

## Windows 阻止运行怎么办

只使用自己构建或来自可信来源的 EXE。企业电脑如果受到安全策略限制，应联系管理员审核，不要尝试绕过组织安全规则。
