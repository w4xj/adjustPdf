# 用户使用手册

## 1. 这个工具能做什么

它会消除 PDF 页面的旋转属性，使页面内容与显示方向保持一致。

例如原页面通过 `/Rotate 270` 才能竖向显示，处理后页面仍然竖向显示，但 `/Rotate` 会变成 `0`。

## 2. 使用前准备

普通用户只需要一个文件：

```text
PDF-如一.exe
```

不需要安装 Python、pypdf、PyInstaller 或其他 PDF 软件。

## 3. 重要签章风险提示

本工具会重新写入 PDF 页面内容，仅建议用于未加盖电子印章、未进行数字签名的文件。

```text
处理已签章或已签名的 PDF，
会导致新生成文件的签名验证失效。
```

程序不会覆盖原始 PDF，但请务必保留原始签章文件，并使用原文件进行验签、归档或正式提交。

点击“开始处理”后，程序会先执行标准 PDF 数字签名结构检查。如果检测到 `/FT /Sig`、有效 `/V`、`/ByteRange` 和 `/Contents` 等已签署结构，会显示风险确认窗口：

```text
取消处理
我已了解风险，仍然继续
```

默认选择“取消处理”。只有明确选择“我已了解风险，仍然继续”后，程序才会生成签名失效的新 PDF。

需要注意：本工具只判断是否存在标准 PDF 数字签名结构，不验证证书链、吊销状态、时间戳或法律效力；仅有图片红章、Stamp 批注或厂商自定义印章格式时，也可能无法确认它是否属于有效数字签名。
## 4. LTY 背景皮肤

程序使用 PySide6 和 `assets/lty.jpg` 制作全窗口 LTY 背景。0.5.2 起四张高透明玻璃卡片，以及表格、输入框、按钮都会尽量透出原图；界面功能分为：标题和红色签章风险警示、PDF 文件列表与文件操作、处理选项、进度与状态。卡片四周和卡片之间都能看到壁纸，不再由一整块面板遮住背景。

红色警示条用于强调：修改已签署 PDF 会导致原签名或电子印章验证失效。皮肤只改变程序外观，不会改变旋转固化、签名检测和输出命名。背景加载失败时，程序仍会以深色底色运行。

背景来源、界面分层、资源替换和重新构建说明见：[LTY 界面皮肤完整说明](SKIN.md)。

## 5. 双击使用

1. 双击 `PDF-如一.exe`；
2. 点击“添加 PDF”，可以一次选择多个文件；
3. 建议先点击“检查页面旋转”，确认旋转页和签名状态；
4. 默认处理模式是“仅处理第一页”；
5. 输出位置留空时，结果保存在原文件旁边；
6. 点击“开始处理”，程序会先执行数字签名预检；
7. 如果检测到签名，确认风险后才会继续；
8. 等待“处理完成”提示。

输出名称示例：

```text
输入：聊天记录.pdf
输出：聊天记录_旋转已固化.pdf
```

如果同名文件已经存在，会生成 `聊天记录_旋转已固化_2.pdf`。程序不会覆盖原始 PDF。

## 6. 拖到 EXE 上使用

1. 在 Windows 文件资源管理器中选中一个或多个 PDF；
2. 把它们拖到 `PDF-如一.exe` 图标上；
3. 程序会打开，并自动把这些 PDF 加入列表；
4. 点击“开始处理”。

也可以把一个或多个 PDF 直接拖进已经打开的程序窗口，程序会自动去重并加入文件列表。

## 7. 检查页面旋转

添加一个或多个 PDF 后，可以先点击：

```text
检查页面旋转
```

这个操作只读取 PDF，不会修改或生成文件。程序会逐页检查解析器计算出的有效 `Rotate`，并在可滚动结果窗口中显示：

- 文件路径；
- PDF 总页数；
- 带旋转属性的页面数量；
- 每个旋转页面的页码；
- 每个页面的旋转角度；
- 每个页面的底层宽度和高度；
- 是否检测到标准 PDF 数字签名或电子签章结构。

    如果检测到签名，报告会按**签署事件**分组，显示每个事件的证书信息
    （签名人、证书序列号、颁发机构、有效期），以及该事件包含的签名字段列表。

例如：

```text
文件：2081980609123209218.pdf
总页数：3
检查结果：未发现页面旋转属性。

数字签名检查：检测到 9 个已写入签名数据的字段，分属 3 次签署事件。

签署事件 1
  签名人：张雨涛
  签名时间：2026-07-28 14:31:15
  证书序列号：65e241071662a9b87148c72be7e083876959f1da
  证书颁发机构：C=CN,O=SCCATESTSM2,OU=TESTSM2,CN=SCEGBTESTSM2
  证书使用人：张雨涛
  证书有效期：2026-04-02 11:45 至 2027-04-02 11:45
  签名验证结果：验证成功
  是否使用时间戳：是
  包含签名字段：4 个
    - 字段：2026628_1785220274892_h04217y3ia1，位置：第 1 页
    - 字段：2026628_1785220274892_h04217y3ia2，位置：第 1 页
    - 字段：2026628_1785220274892_h04217y3ia3，位置：第 1 页
    - 字段：2026628_1785220274892_h04217y3ia4，位置：第 1 页

  签名人：张雨涛
  签名时间：2026-07-28 14:32:26
  证书序列号：65e241071662a9b87148c72be7e083876959f1da
  ...

```

如果有多个 PDF 同时检查，报告之间用分隔线隔开。

如果没有旋转页面，会显示：

```text
未发现页面旋转属性
```

检查使用 PDF 解析器读取页面的有效属性，不是简单搜索 PDF 二进制文本中的 `/Rotate`，因此可以识别对象流、压缩对象和页面树中的有效旋转。

建议操作顺序：

```text
添加 PDF
  → 检查页面旋转（确认旋转状态）
  → 检查页面属性（查看每页宽高和旋转）
  → 确认目标页码
  → 选择处理模式
  → 开始处理
```

## 8. 检查页面属性

添加一个或多个 PDF 后，点击"检查页面属性"按钮：

程序会逐页读取以下信息并显示在结果窗口：

- 页面的**宽（Width）**和**高（Height）**，单位 pt（点，1 pt = 1/72 英寸），明确标注哪个是宽哪个是高；
- 页面的**旋转（Rotate）**角度。

例如：

```text
文件：20260722.pdf
总页数：397

第 1 页：旋转角度：270°，841.92（宽） × 595.20（高）
第 2 页：旋转角度：0°，595.20（宽） × 841.92（高）
```

这个功能与"检查页面旋转"的区别：

| 功能 | "检查页面旋转" | "检查页面属性" |
|------|--------------|--------------|
| 显示范围 | 只显示有旋转的页面 | 显示全部页面 |
| 信息详情 | 旋转角度、宽（Width）、高（Height）、注释、签名检测 | 宽、高、旋转，每页独立行 |
| 尺寸标注 | 明确标注宽（Width）和高（Height） | 明确标注宽（Width）和高（Height） |
| 主要目的 | 快速确认哪些页面需要处理 | 全面了解每页的尺寸和方向 |

## 9. 修复 PDF 结构

当“检查页面旋转”或“检查页面属性”提示 `Could not read Boolean object`，并且文件属于异常空 xref 或重复对象映射时，可以点击：

```text
修复 PDF 结构
```

修复操作只重建 PDF 的交叉引用表和对象结构，不固化旋转，也不主动修改页面内容。程序会生成新文件：

```text
输入：材料.pdf
输出：材料_结构已修复.pdf
```

执行前会进行严格的签章安全检查：

- 检测到已写入的标准数字签名或电子签章时，直接禁止修复；
- 检测到 `/Subtype /Stamp` 印章批注时，直接禁止修复；
- 无法完整检查页面批注时，为安全起见也会禁止修复；
- 此操作没有“仍然继续”选项，不能绕过签章检查。

写入完成后，程序会重新用标准 PDF 读取方式验证新文件，并比较页数、页面尺寸、裁剪框、旋转、页面内容流和批注状态。任一项目不一致时不会生成最终输出文件。

注意：如果红章只是页面内容中的普通图片，且没有标准数字签名或 Stamp 批注结构，程序无法仅凭视觉判断它是否属于有效印章。此类文件仍应由人工确认。

## 10. 处理页面选项

程序提供三种处理方式，默认选中“仅处理第一页”。

### 仅处理第一页

只在第一页旋转不为 `0` 时处理第一页，其他页面保持原状。

这是默认模式，适合你当前“第一页是扫描件并带有旋转属性”的场景。

### 所有存在旋转属性的页面

处理 PDF 中所有 `Rotate` 不为 `0` 的旋转页面。通常适合希望整个 PDF 都清除旋转属性的情况。

### 按页码处理

选择后会出现页码输入框，输入类似：

~~~text
1,5-9,12
~~~

表示处理第 1、5、6、7、8、9、12 页。

输入规则：

- 使用英文逗号 `,` 分隔页码；
- 使用短横线 `-` 表示包含首尾的范围；
- 可以输入空格，程序会自动忽略首尾空格；
- 重复页码会自动去重；
- 页码必须从 1 开始；
- 页码超出某个 PDF 的总页数时，该文件会处理失败并显示原因；
- 空输入、倒序范围、中文逗号和其他文字会显示格式错误。

~~~text
正确：1,5-9,12
正确：1, 5-9, 12
错误：1，5-9,12
错误：9-5
错误：0,2
~~~
## 11. 输出位置

- 使用原目录：结果保存在每个输入 PDF 的旁边；
- 选择文件夹：所有处理结果保存到指定目录。

## 12. 状态说明

- `等待处理`：尚未开始；
- `处理中`：正在读取或写入 PDF；
- `成功`：处理完成；
- `成功（有警告）`：PDF 已生成，但建议人工检查；
- `失败`：没有生成有效结果，错误原因会显示在列表中。

## 13. 常见警告

### 页面包含链接、批注或表单区域

页面内容已经处理，但当前引擎不保证所有交互区域坐标都同步变换。请打开输出 PDF，检查链接点击区域或表单控件。

### 没有处理任何页面

这通常表示所有页面的旋转属性原本就是 `0`。程序仍会生成一个新 PDF，但不会修改页面方向。

## 14. 安全说明

- 不上传 PDF；
- 不覆盖原文件；
- 不读取或保存 PDF 密码；
- 处理失败时会清理临时文件；
- 建议首次处理重要 PDF 后人工打开检查。

## 15. 当前版本不会做什么

- OCR 识别扫描文字；
- 导出 TXT；
- 修复扫描图像本身的倾斜；
- 压缩、合并或拆分 PDF；
- 破解 PDF 密码。
