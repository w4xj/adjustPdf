# LTY 界面皮肤说明

## 1. 皮肤来源

当前背景源图：

```text
assets/lty.jpg
```

源图尺寸：

```text
2560 × 1440
16:9
```

构建时会生成 Tkinter 可以直接加载的 PNG：

```text
resources/skins/lty.png
```

## 2. 视觉设计

LTY 皮肤采用：

- 全窗口背景图；
- 背景居中显示并根据窗口尺寸裁剪；
- 深蓝色内容面板；
- 暖金色按钮和表头；
- 浅色文字；
- 高对比度文件列表；
- 暖黄色签章风险提示。

Tkinter 不支持真正的实时毛玻璃透明，因此内容面板使用稳定的深色卡片效果，确保文件名、页码、签名提示和错误信息清晰可读。

## 3. 自适应行为

窗口调整大小时：

```text
背景图保持居中
内容面板保持四周留白
文件列表自动扩大或缩小
按钮、处理选项和状态栏保持原有布局
```

背景图不会参与 PDF 处理，不会影响输出文件。

## 4. 资源生成

如果修改了 `assets/lty.jpg`，可以重新生成皮肤资源：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\create_skin_assets.ps1
```

构建脚本在 `resources/skins/lty.png` 不存在时也会自动生成。

## 5. 功能独立性

皮肤只修改 GUI 显示层，没有修改：

- PDF 旋转检查；
- 数字签名预检；
- 页码范围解析；
- PDF 写出逻辑；
- 文件命名；
- 自动化测试；
- 命令行模式。
